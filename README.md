# Genetic Algorithm — Задача коммивояжёра (TSP)

Реализация генетического алгоритма для поиска оптимального маршрута через все вершины в матрице смежности с возвратом в начальную точку.

![Python](https://img.shields.io/badge/Python-3.10+-blue)

## Как работает

Алгоритм моделирует эволюцию: создаёт популяцию случайных маршрутов и улучшает их через отбор, кроссовер и мутацию. Процесс останавливается, когда N поколений подряд не дают улучшения.

**Основные этапы:**
1. **Инициализация** — генерация случайных маршрутов
2. **Оценка** — расчёт длины каждого маршрута (fitness = 1 / расстояние)
3. **Отбор** — рулеточный метод с вероятностью пропорциональной fitness
4. **Кроссовер (OX)** — упорядоченный кроссовер для сохранения корректности маршрута
5. **Мутация** — инверсия случайного сегмента маршрута
6. **Элитизм** — 10% лучших особей переходят в новое поколение без изменений

## Пример работы

Матрица 14×14 из `input.txt`, популяция 100, 500 поколений без улучшений, мутация 0.3, старт из вершины 0:

```
Кратчайший маршрут: 0 → 10 → 13 → 2 → 1 → 4 → 7 → 11 → 5 → 9 → 3 → 12 → 8 → 6 → 0
Длина маршрута: 147
Поколений до сходимости: 263
```

*Результат может отличаться — алгоритм стохастический.*

## Формат входных данных

Матрица смежности в текстовом файле — числа через пробел, каждая строка = одна вершина:

```
0 23 75 63
76 0 94 94
40 9 0 41
89 35 62 0
```

## Параметры

| Параметр | Рекомендуемые значения | Описание |
|---|---|---|
| Размер популяции | 50–200 | Больше = точнее, но медленнее |
| Поколений без улучшений | 200–1000 | Критерий остановки |
| Вероятность мутации | 0.1–0.5 | Баланс между исследованием и эксплуатацией |
